# 抖音限制助手

一个 Android 应用，用于在指定时间段自动阻止打开抖音，帮助你保持良好的作息习惯。

## 功能特点

- ⏰ **自定义时间**：可设置任意时间段进行限制（默认 22:00 - 06:00）
- 🚫 **完全阻止**：检测到抖音运行时立即覆盖全屏阻止界面
- 📅 **白名单日期**：可设置周末或特定日期不限制
- 🔓 **临时解锁**：设置密码后可在阻止界面临时解锁 10 分钟
- 🔄 **开机自启**：手机重启后自动启动监控服务
- 💤 **持续保护**：后台服务持续运行

## 使用步骤

### 1. 构建应用

在 Android Studio 中打开项目，或使用命令行构建：

```bash
cd DouyinBlocker
./gradlew assembleDebug
```

生成的 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`

### 2. 安装应用

将 APK 安装到手机上：

```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```

### 3. 授予权限

打开应用后，点击"授予权限"按钮，需要授予两个权限：

1. **使用情况访问权限**：用于检测抖音是否在运行
2. **显示在其他应用上层权限**：用于显示阻止界面

### 4. 配置设置（可选）

点击"⚙ 设置"按钮，可以自定义：

- **限制时间段**：设置开始和结束时间
- **白名单日期**：选择哪些星期几不限制（例如周末）
- **解锁密码**：设置密码用于临时解锁

### 5. 启动服务

配置完成后，点击"启动监控服务"按钮，服务将在后台运行。

## 工作原理

1. 应用启动一个前台服务，每 500 毫秒检查一次当前时间和前台应用
2. 根据配置判断当前是否在限制时段，且不在白名单日期内
3. 如果检测到抖音在前台运行，立即启动全屏阻止界面
4. 阻止界面会持续检查抖音是否关闭，用户可以输入密码临时解锁

## 配置说明

### 时间段设置

- 默认：22:00 - 06:00（跨天）
- 可设置同一天内的时间段，例如：08:00 - 22:00
- 支持跨天时间段

### 白名单日期

勾选后，该日期不会进行任何限制：
- 周一到周日任意组合
- 例如：勾选"周六"和"周日"可实现工作日限制，周末自由

### 临时解锁

- 在设置中配置密码
- 阻止界面会显示密码输入框
- 输入正确密码后解锁 10 分钟
- 10 分钟后自动恢复限制

## 系统要求

- Android 6.0 (API 23) 及以上
- 需要授予使用情况访问和悬浮窗权限

## 注意事项

- 部分手机可能需要在电池优化设置中将本应用设为"不优化"，避免服务被系统杀死
- 小米、华为等手机需要在自启动管理中允许本应用自启动
- 某些定制系统可能需要额外的后台运行权限
